# Opera Growth Audit

**Live → https://eddieatadapty.github.io/opera-flow-rebuild/**

Five ideas to turn more Opera users into subscribers, each built into a clickable version of Opera's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Open on the ad’s promise, already switched on | +10–15% CR to purchase |
| 02 | Ask one question, and use it on the paywall | +10–15% CR to purchase |
| 03 | A first win before any price | +5–15% CR to purchase |
| 04 | Sell VPN Pro where the free VPN stops | +10–20% CR to purchase |
| 05 | Catch the close with a real second plan | +10–15% ARPU |

Every price, rating and feature comes from Opera's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Opera. VPN Pro is not sold in the iOS app today, so the first test is the paywall itself. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
